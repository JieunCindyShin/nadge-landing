# 냈지 NADGE

> 마감이 쏟아질 때, 냈지?

**👉 페이지 보기: https://nadge-landing.parallax.kr**

공모전 마감, 발표일, 제출 파일을 챙겨주는 앱 "냈지"의 랜딩 페이지예요. Parallax 해커톤 「랜딩톤」 출품작이에요. [Parallax Cloud](https://cloud.parallax.kr)로 배포했어요.

## 둘러보기

- 첫 화면의 마감 카드를 톡톡 눌러 "냈지!" 도장을 찍어보세요. 다 찍으면 제목이 바뀌어요. 카드를 잡아서 던질 수도 있어요.
- 휴대폰으로 열면 "폰 기울이기"로 카드를 쏠리게 할 수 있어요.
- 스크롤하면 흩어진 카드가 휴대폰 화면 속 목록으로 정리돼요.
- "미리 써보기"에서 마감을 넣고 "냈어요"를 누르면 결과 발표일 등록, 발표 날 결과 확인, 수상 기록까지 이어져요. 맨 위의 예시로 "붙었어요"를 바로 눌러볼 수도 있어요.
- 마지막 "한 해 기록"에서는 도장이 달별 칸에 떨어져 쌓이면서 막대그래프가 돼요. 도장을 누르면 무슨 공모전인지 보여주고, 미리 써보기에서 낸 것과 수상도 여기에 쌓여요. (예시 기록)

## 내 컴퓨터에서 직접 실행하기 (개발자용)

페이지를 보기만 하려면 위의 링크를 누르면 돼요. 이 부분은 코드를 내려받아 직접 고쳐보고 싶은 사람을 위한 안내예요.

빌드 과정 없이 `index.html`, `style.css`, `main.js` 세 파일로 돌아가요. 코드를 내려받은 폴더에서 아래 명령을 실행해요. (Python 3이 설치되어 있어야 해요.)

```bash
python3 -m http.server 4321
```

그다음 내 컴퓨터의 브라우저에서 http://localhost:4321 을 열어요. `localhost`는 "지금 쓰고 있는 이 컴퓨터"라는 뜻이라, 명령을 실행한 컴퓨터에서만 열려요.
